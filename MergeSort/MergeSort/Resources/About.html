Справка к программе сортировка массивов

О программе

Программа предназначена для решении задачи сортировки массива заданными методами: сортировка слиянием (MergeSort), сортировки пузырьком(BubbleSort), быстрая сортировка (QuickSort). Она отсортировывать массив выбранным способом а так же выводить количество перестановок и сравнений.

Теоретические сведения

1. Сортировка слиянием (MergeSort)

Принцип работы: Алгоритм использует стратегию "разделяй и властвуй". Массив рекурсивно разделяется на две части до тех пор, пока не останутся подмассивы из одного элемента, которые затем сливаются в упорядоченные массивы.

Характеристики:

  • Сложность: O(n log n) во всех случаях
  • Требует дополнительной памяти O(n)
  • Устойчивая сортировка

Применение: Эффективен для больших массивов, особенно когда требуется стабильная сортировка. Часто используется для сортировки связных списков.

2. Сортировка пузырьком (BubbleSort)

Принцип работы: Алгоритм последовательно сравнивает соседние элементы и меняет их местами, если они находятся в неправильном порядке. Процесс повторяется до тех пор, пока массив не будет отсортирован.

Характеристики:

  • Сложность: O(n²) в худшем и среднем случае, O(n) в лучшем (уже отсортированный массив)
  • Не требует дополнительной памяти (сортировка на месте)
  • Устойчивая сортировка

Применение: Используется преимущественно в учебных целях из-за простоты реализации. На практике применяется редко из-за низкой эффективности.

3. Быстрая сортировка (QuickSort)

Принцип работы: Алгоритм выбирает опорный элемент, разделяет массив на две части (элементы меньше опорного и больше опорного), затем рекурсивно сортирует эти части.

Характеристики:

  • Сложность: O(n log n) в среднем случае, O(n²) в худшем (редко)
  • Сортировка на месте (требует O(log n) дополнительной памяти для стека вызовов)
  • Неустойчивая сортировка

Применение: Один из самых быстрых алгоритмов на практике. Широко используется в стандартных библиотеках языков программирования.

4. Сравнение методов сортировки

Метод Лучший случай Средний случай Худший случай Память Устойчивость
MergeSort O(n log n) O(n log n) O(n log n) O(n) Да
BubbleSort O(n) O(n²) O(n²) O(1) Да
QuickSort O(n log n) O(n log n) O(n²) O(log n) Нет

5. Количество сравнений и перестановок

В программе отслеживаются две ключевые метрики:

  • Сравнения - количество операций сравнения элементов
  • Перестановки - количество операций обмена элементов местами

Эти показатели помогают оценить эффективность каждого алгоритма для конкретного набора данных.

Хранение данных в приложении

1. База данных

Программа автоматически создает и использует базу данных SQLite в файле arrays.db. База содержит таблицы для хранения:

  • Исходных (неотсортированных) массивов
  • Результатов сортировки
  • Статистики выполнения операций (количество перестановок, сравнений)

2. Структура хранения

Для эффективного хранения числовых данных используется специальный формат:

  • Массивы чисел сохраняются в бинарном виде для экономии места
  • Поддерживается хранение как исходных, так и отсортированных данных
  • Для каждой операции сохраняется тип использованного алгоритма сортировки
  • Фиксируется точное время выполнения операции

3. Работа с данными

Программа предоставляет следующие возможности:

  • Автоматическое сохранение результатов каждой сортировки
  • Обновление существующих записей
  • Удаление данных из базы
  • Защита от дублирования одинаковых массивов

4. Особенности реализации

Система хранения данных обладает следующими характеристиками:

  • Используется технология Entity Framework для удобной работы с базой
  • Реализована проверка целостности данных при сохранении
  • Поддерживается подтверждение действий при изменении существующих записей
  • Обеспечивается высокая производительность даже с большими массивами
  • Все ошибки обработки данных корректно перехватываются и сообщаются пользователю

5. Управление данными

Пользователь может:

  • Просматривать выполненные сортировок
  • Сравнивать производительность разных алгоритмов
  • Экспортировать результаты в различные форматы
  • Удалять ненужные данные для экономии места

Инструкция по использованию

1. Основные возможности

Программа предоставляет следующие функции:

  • Сортировка числовых массивов тремя методами: слиянием, пузырьком и быстрая сортировка
  • Хранение истории сортировок во встроенной базе данных
  • Импорт/экспорт данных в форматах TXT и Excel
  • Просмотр статистики сортировки (количество сравнений и перестановок)

2. Работа с массивами

2.1. Ввод данных:

  • Введите числа массива через пробел в поле ввода
  • Или импортируйте массив из файла (поддерживаются TXT и Excel форматы)

2.2. Сортировка массива:

  1. Выберите метод сортировки из выпадающего списка
  2. Нажмите кнопку "Сортировать"
  3. Просмотрите результаты в соответствующих полях:
    • Отсортированный массив
    • Количество перестановок
    • Количество сравнений

3. Работа с базой данных

Все операции автоматически сохраняются в локальную базу данных SQLite:

  • Сохранение: нажмите "Сохранить" для записи текущего массива в базу
  • Просмотр истории: отображаются все сохраненные массивы
  • Удаление: удалите ненужные записи из базы данных

4. Импорт и экспорт данных

4.1. Импорт массивов:

  • Из TXT: файл должен содержать числа, разделенные пробелами
  • Из Excel: поддерживается импорт из первой строки листа

4.2. Экспорт результатов:

  • В TXT: сохраняет исходный массив, метод сортировки, статистику и результат
  • В Excel: создает структурированный отчет с данными сортировки

5. Дополнительные функции

  • Просмотр справки о программе (меню "О программе")
  • Очистка полей ввода для создания нового массива
  • Фильтрация сохраненных массивов (отсортированные/неотсортированные)

6. Рекомендации

  • Для больших массивов (более 1000 элементов) используйте быструю сортировку
  • Регулярно экспортируйте важные данные во внешние файлы
  • При возникновении ошибок проверьте формат вводимых данных
